Warfare Alife Overhaul
version: 1.6.2
by Vintar - GAMMA patch and continued development by Erepb/SaloEater

for Anomaly 1.5.3, including GAMMA (use the Gamma Patch in the installer)


To install via Mod Organizer:

1. Import the WarfareALifeOverhaul.zip file into Mod Organizer
2. Follow the installer, selecting any optionals and patches necessary. Check that your load order has WarfareALifeOverhaul overwriting any addons you selected patches for.
3. On GAMMA, select the 'Gamma Patch' module together with the 'ZCP' and 'LTTZ' patches - GAMMA ships both of those addons. The 'Alternative New Levels Layout' patch is optional and requires the New Levels addon.
4. Load the 'Alife Overhaul - Balanced' preset: Options > Alife > Warfare, then pick it from the preset dropdown at the top right of the screen. Balanced is the recommended one and the preset kept current with this addon's balance changes; the other 'Alife Overhaul' presets run at fixed 1x, 2x, 5x and 10x pacing. Apply a preset BEFORE starting a new game, otherwise respawn timer changes will not take place until the next respawn occurs.


To install manually:
1. Drop the 'gamedata' folder found inside 'src' into your Anomaly root directory (merge it with your existing 'gamedata' folder).
2. Install any optionals desired - every folder under 'optionals' holds its own 'gamedata' folder, merged the same way.
3. Install any patches that are needed, from the 'patches' folder, the same way. On GAMMA that means 'GAMMA Warfare Patch', 'ZCP' and 'Patch for LTTZ Directors Cut'.
4. Load the 'Alife Overhaul - Balanced' preset: Options > Alife > Warfare, then pick it from the preset dropdown at the top right of the screen. Balanced is the recommended one and the preset kept current with this addon's balance changes; the other 'Alife Overhaul' presets run at fixed 1x, 2x, 5x and 10x pacing. Apply a preset BEFORE starting a new game, otherwise respawn timer changes will not take place until the next respawn occurs.

NOTE: The fomod folder is not used if you do not use Mod Organizer, or are installing this addon manually.

NOTE: Workbenches are covered - Hawkie's Warfare Mechanic Fix is bundled, no separate download needed. Every vice belongs to one story mechanic, and the game reads the toolkits it offers off that mechanic; in Warfare he is usually dead or was never spawned, so the toolkits you hand to a Warfare faction mechanic never reach any bench. The bundled fix sources them from the mechanic of the faction holding the smart terrain instead. It stands down when the Gamma Patch is installed, since GAMMA ships its own workbench script and its workshop already counts toolkits you keep in a nearby stash.

NOTE: The per-faction 'Participate in Warfare' switch no longer exists. Every faction always takes part in warfare


Description:

Warfare is an extremely cool idea, but its implementation with Anomaly is somewhat... incomplete. It deserves to be more than a tacked-on mode. This addon aims to fix that through a combination of bug-fixing and new features.

This addon is compatible with existing Anomaly 1.5.3 Warfare save files, and has no impact on non-warfare games - every change it makes to a base game function is guarded and defers to the original outside warfare mode. Warfare state saved by older versions of this addon is migrated on load.

The base game scripts this addon used to overwrite - dialogs, game_relations, xr_logic, xr_conditions,
xr_effects, sim_squad_scripted, tasks_assault, tasks_smart_control, ui_mm_faction_select, ui_options,
axr_task_manager, task_objects - are monkey-patched at runtime instead, from
warfare_monkeypatches.script, warfare_monkeypatches_sim_squad.script and modxml_warfare.script. Each
override falls back to the original function when warfare mode is off.
